# Lab notebook

Every group keeps a lab notebook here: one Markdown file per working session, named
`YYYY-MM-DD_group<X>.md`. Write it as you go. It's your memory, and it shows how
you reached your conclusions, including the dead ends.

Do not paste data tables into the notebook. A few key numbers are fine, but no full
tables. The notebook is committed to git.

```markdown

...
```
